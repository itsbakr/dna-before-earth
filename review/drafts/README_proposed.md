# Can Genome Size Date the Origin of Life?

*A reproducible, pre-registered re-test of the "genome complexity clock" (Sharov 2006).*

> **Proposed replacement README (draft).** Not yet applied. The current README's headline claims are not
> supported by the analyses in this repository; see `review/CRITIQUE_AND_RESEARCH_PLAN.md`.

## The question

In 2006 Alexei Sharov plotted the functional genome size of five groups of organisms against the time each
group appeared. The points fell on a straight line on a log scale. Extrapolated back to a single nucleotide,
the line reached about 10 billion years ago, twice the age of the Earth. If genome complexity really grows at
a constant rate, life began before Earth.

We asked whether that method can be trusted, and tested it with the data available in 2026.

## What we found

| Test | Result |
|---|---|
| Reproduce Sharov's regression | Exactly reproduced (8.64 + 0.89x, R² 0.97). Within the straight-line model the pre-Earth date is statistically firm. |
| Does the method recover a known answer? | No. Statistics built from living species cannot see a uniform clock, and produce a "clock" with no trend at all. In simulations where life began on Earth, the method still said "before Earth" in up to 100% of runs. |
| 17,198 measured genomes on the Timetree of Life | Trendless evolution reproduces the observed slopes. Different lineages imply origins from 5.5 to 16.4 billion years ago. |
| Prokaryotes since LUCA (GTDB, 36,268 species) | Near-stasis: up to a fifth of modern species have genomes smaller than LUCA's. |
| **Pre-registered:** gene families in ancestors (eggNOG 6) | Gene content grows about 0.19 log10 per Gyr; a constant rate extrapolates to one gene family 22.5 billion years ago, before the Big Bang. **The clock is not supported.** |
| **Pre-registered:** genome sizes of extinct species (fossils) | [pending] |
| What a terrestrial origin requires | The genome doubling every 10 to 15 million years before LUCA. |

**Bottom line:** genome size and gene content cannot date the origin of life. The data are consistent with
complexity rising quickly at the start and in bursts at major transitions, not at a constant rate. Panspermia
is not ruled out; it simply gets no support from this line of evidence.

## Reproduce everything

```bash
pip install -r requirements.txt
make reproduce        # offline: replication, statistics, simulation calibration (~1 min)
make reproduce-all    # adds the real-data and pre-registered tests (downloads ~11 GB)
```

All numbers are generated by code; `results/RESULTS.md` is built from the JSON outputs.

## How this was done

The project began as an AI-assisted replication. An audit of that first pass found hard-coded numbers, data
errors and claims the code did not support; they are documented in the review and corrected here. Every
analysis is now tested, generated from data, and pre-registered where it matters. We think that is the right
way to use AI in science: fast, but auditable.
